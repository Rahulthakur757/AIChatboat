# 🎓 College AI Assistant

A simple AI-powered chatbot that answers college-related questions using information stored in PDF documents. The chatbot uses Retrieval-Augmented Generation (RAG) to search the uploaded PDFs and generate accurate responses.

---

## Features

- PDF Knowledge Base
- Automatic PDF Text Extraction
- Text Chunking
- OpenAI Embeddings
- Semantic Search
- AI-powered Question Answering
- Responsive Chat Interface

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### AI & RAG
- OpenAI API
- OpenAI Embeddings
- Retrieval-Augmented Generation (RAG)

## Installation

Install dependencies

```bash
npm install
```

Start the server

```bash
npm start
```

## Example Questions

- What is the MCA fee?
- What courses are available?
- What is the admission process?
- What are the examination guidelines?
- What is the fee payment method?
