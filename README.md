# ⚡ NTPC Limited AI Assistant & RAG Knowledge Base

A simple AI-powered chatbot that answers NTPC-related questions using information stored in PDF documents. The chatbot uses Retrieval-Augmented Generation (RAG) to search the uploaded PDFs and generate accurate responses.

---

## Features

- PDF Knowledge Base
- Automatic PDF Text Extraction
- Text Chunking
- OpenAI Embeddings
- Semantic Search
- AI-powered Question Answering
- Responsive Chat Interface

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### AI & RAG
- OpenAI API
- OpenAI Embeddings
- Retrieval-Augmented Generation (RAG)

## Installation

Install dependencies

```bash
npm install
```

Start the server

```bash
npm start
```
